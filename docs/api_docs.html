Introduction

Welcome to the Cobra Shop API documentation. This RESTful API provides access to all e-commerce functionality including products, cart management, orders, reviews, and administrative features.

Base URL

http://localhost/Database_Project/

Response Format

All responses are returned in JSON format with the following structure:

{
    "success": true,
    "data": { ... },
    "message": "Optional message"
}

CSRF Protection

All POST, PUT, and DELETE requests require a CSRF token in the request header:

X-CSRF-Token: your_csrf_token_here

Authentication

The API uses session-based authentication. Users must be logged in to access protected endpoints.

POST /login.php

Request Body

Parameter Type Required Description
email string Yes User email address
password string Yes User password

Example Response

{
    "success": true,
    "message": "Login successful",
    "data": {
        "user_id": 1,
        "name": "John Doe",
        "email": "john@example.com",
        "role": "customer"
    }
}

Error Handling

The API uses standard HTTP status codes and returns detailed error messages.

Status Code Description
200 Success
400 Bad Request - Missing or invalid parameters
401 Unauthorized - Authentication required
403 Forbidden - Insufficient permissions
404 Not Found - Resource doesn't exist
429 Too Many Requests - Rate limit exceeded
500 Server Error - Internal error occurred

Error Response Format

{
    "success": false,
    "error": "Error message description",
    "code": "ERROR_CODE"
}

Get Products

Retrieve a list of products with optional filtering and pagination.

GET /get-products.php

Query Parameters

Parameter Type Default Description
category integer - Filter by category ID
search string - Search term for product names
min_price number - Minimum price filter
max_price number - Maximum price filter
sort string name Sort field (name, price, created_at)
order string asc Sort order (asc, desc)

Example Request

GET /get-products.php?category=1&sort=price&order=asc

Example Response

{
    "success": true,
    "data": [
        {
            "product_id": 1,
            "name": "Wireless Headphones",
            "description": "High-quality wireless headphones",
            "price": 99.99,
            "stock_quantity": 50,
            "category_id": 1,
            "category_name": "Electronics",
            "image_url": "images/products/headphones.jpg",
            "avg_rating": 4.5,
            "review_count": 12
        }
    ],
    "total": 25,
    "page": 1,
    "per_page": 12
}

Query Parameters

Parameter Type Default Description

  • Customer statistics
  • Daily sales trends
  • Top selling products
  • Category performance
  • Staff performance metrics
  • Low stock alerts
